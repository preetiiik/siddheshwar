# Solution page assets

Six dedicated solution experiences reuse the existing Siddheshwar design system and project images. The supplied brief names Shreem Controls; Siddheshwar branding, Playfair Display / Clash Display and the existing charcoal, ivory and champagne styling are retained.

Existing solution listing anchors, service routes, contact forms and WhatsApp navigation remain available. Homepage cards and listing actions now link to the six detail routes under `/solutions/`.

Lighting uses S2/S3/S6 architectural and interior scenes; curtains use S4 and the existing curtain-controller installation; climate uses S5 and the climate-controller installation; entertainment uses the supplied cinema scene and S6; complete automation uses S1, the supplied HyPanel Supreme installation and the existing intelligent-spaces image.

Security uses supplied SL60/SL30 smart-lock installations and the original Akubela door/window sensor. No verified CCTV, video-door-phone or security mobile-interface imagery exists in the project; these missing assets have not been replaced with unrelated photographs or generated equipment. Security content retains the supplied capability descriptions with installation and compatibility qualifications.

All consultation actions use the existing `/contact?interest=...` flow. No connectivity, compatibility or security performance is simulated.
