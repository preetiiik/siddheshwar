# Product collection pages

Seven guides are available at `/products/categories/:categorySlug` and are linked from the selected category heading on the Products page. Existing `/products?category=...` filtering, homepage category navigation, individual Akubela pages and product detail dialogs are preserved.

Each guide uses the supplied product and brand names verbatim, with 38 model entries total. No specifications, prices or compatibility guarantees were added. The supplied brief names Shreem Controls; the implementation retains Siddheshwar branding, Clash Display, light neutral surfaces and navy accents.

The user explicitly approved dummy images. Aura Series Smart Switch, iON Prime PB KNX and iON Prime CP4 KNX use existing exact product photography. The remaining 35 models use distinct local SVG placeholder illustrations under `public/products/collection-placeholders/`. These are labelled illustrative artwork, do not depict model-specific hardware and can be replaced through `product-collection-details.json`. They are presentation entries rather than invented technical product records.

Existing category photography is used for context in hero and overview sections, with residential or commercial application imagery. Door Lock Systems uses residential architecture rather than labelling Akubela lock photography as OneTouch equipment.

All model enquiries and final CTAs use the existing contact interest flow. Category guide links return to the correct catalogue filter.

The approved 38-entry list is retained as an input to the unified catalogue, merged with all 79 Akubela source records. See catalogue-merge-report.md for the current 116-record total, duplicate resolution and verification notes. The category galleries now use the same canonical data as the Products page.
